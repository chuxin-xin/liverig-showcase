## 不支持 / 不建议

- 32 位 VST3：当前宿主不加载。
- 需要 iLok / 硬件加密狗但本机未授权的插件：加载会失败。
- 依赖独立 GUI 服务或外部引擎的插件：可能能加载，但参数与音频不稳定。
- 采样率与宿主不一致且内部不重采样的插件：可能出现静音或爆音。

> 插件商标归各厂商所有；本列表只表示“在本机测试环境中能出声”，不代表厂商背书。
