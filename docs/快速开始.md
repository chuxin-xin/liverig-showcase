# 快速开始

## 1. 准备

- Windows 10 / 11，64 位；
- 你的声卡驱动已装好，系统声音里能看到输入和输出端点；
- 如果要走虚拟通道，先自己装好 VB-CABLE / VoiceMeeter / BlackHole 等；LiveRig 不代装驱动。

## 2. 启动

解压试用包，运行 `LiveRig`（或 `run.ps1`）。首次启动先看设备列表：

- **采集**：选你的话筒，或声卡的虚拟输入；
- **回放**：选直播软件要用的输出，或虚拟输出；
- **采样率 / 块大小**：先按设备默认值，不要一上来改到 192 kHz / 64 帧。

## 3. 挂插件

按你的习惯建一条话筒链，例如：

```text
EQ → 压缩 → 限幅
```

原则：

- 先 EQ 修音色，再压缩控动态，最后限幅保峰值；
- 插件不是越多越好，每多一个都会增加延迟和 CPU；
- 先确认每个插件单独能出声，再串链。

## 4. 选通道

如果声卡/虚拟线有多个通道：

- 立体声用 `1/2`；
- 第二组用 `3/4`；
- 单声道用 `1`；
- 多通道虚拟线可选 `1/16` 或 `all`。

改完通道先做一次回环检查：播一个 1 kHz 测试音，再从对应 capture 端点录回来。**能录回、电平正常，才算真的通了。** 静态列表里显示“active”不等于矩阵已经路由。

## 5. 开播前检查

- 原始电平不贴 0 dBFS，表里 `削波 = 0`；
- 输出峰值离 ceiling 还有余量；
- 直播软件里选对了采集设备；
- 连续跑 10 分钟，没有欠载、没有断流。

先看 [常见问题](常见问题.md)，再到 Issues 反馈。反馈时带上：

```text

直播软件：

现象 + 截图：
```
