# 常见问题

## 为什么表里一直有“刺啦 / 电流声”？

先看原始电平，不要先怪插件。直播里多数“电流声”是话筒信号在声卡 ADC 上被削平了：表里 `原始削波 > 0`，或者原始峰值贴着 0 dBFS，就是硬件过载。插件在 ADC 之后，救不了已经切平的波形。

先把声卡增益旋钮降一点，让原始峰值留出余量，再用插件把声音拉响。

## 虚拟通道没有声音 / 回环失败

按顺序查：

1. 系统声音里能不能看到这个 render / capture 端点；
2. 播放端和采集端是不是同一条虚拟线（例如 `CABLE Input` 对 `CABLE Output`）；
3. 通道有没有选对（`1/2` 还是 `3/4`）；
4. 声卡矩阵有没有把对应通道路由过去；
5. 采样率是否一致。

**静态列表显示 active 不等于已经路由。** 以回环检查为准。

## ASIO 设备被占用 / 打不开

- 关掉同时占用 ASIO 的 DAW、直播软件或其他机架；
- 确认采样率和缓冲设置在声卡控制面板与 LiveRig 里一致；
- 不行就先切 WASAPI / MME，确认链路通了，再回 ASIO。

## 3/4 通道能选，但回环是静音

这通常不是软件缺陷，而是声卡矩阵没有把 3/4 路由到对应虚拟端点。先去声卡控制面板把矩阵接好，再做回环。

## 插件加载成功但不出声

- 插件是不是 32 位；
- 是否要求 iLok / 账号授权；
- 插件内部是否被静音、旁通或 solo；
- 插件采样率是否和宿主一致；
- 单独加载这个插件能不能出声。

## 延迟有多大？

取决于声卡缓冲、采样率和插件链。先用设备默认缓冲确认稳定，再逐级降低。直播场景优先稳定，不要为了几毫秒把缓冲压到欠载。

## 支持 macOS / Linux 吗？

端点适配层在验证中，当前不写成“已支持”。Windows 是主验证平台；其他系统以实际枚举和回环结果为准。

## 为什么公开仓库没有源码？

核心引擎、插件桥、插件参数适配库和调音数据是产品本身。公开仓库用于展示、试用申请和问题反馈；完整能力在试用版 / 授权版里。
