# 更新日志

## 0.6.4

- 增加任意 render / capture 端点手动配对；
- 支持按通道选择：`1/2`、`3/4`、单声道、`1/16`、`all`；
- 增加 1 kHz 回环检查，检查通过才允许保存配置；
- 设备列表改为先扫描、带编号展示，用户当场选择；
- 明确支持边界：LiveRig 是宿主机架，不代装、不打包虚拟声卡驱动。

## 0.6.3

- 增加虚拟声卡适配层：扫描、品牌配对、静态检查、回环检查；
- 支持 VB-CABLE、BlackHole、VoiceMeeter、ROUTIST R2 等常见虚拟线；
- 对远程桌面端点标记“不推荐”，避免把远程会话当成本地回环。

## 0.6.x 之前

- VST3 插件链、ASIO / WASAPI / MME 后端；
- strip / bus 混音、发送、限幅、电平表；
- 预设、场景、撤销、审计；
- Agent JSONL 协议与自然语言音色入口。
